Le Language HTML

Présentation du langage:
 Le HTML est une des trois inventions à la base du World Wide Web avec le Hypertext Transfer Protocol connu sous (HTTP) et les adresses web ou (URL). En août 1981 Tim Berners-Lee annonce le web sur "Usenet" il parle uniquement du Standard Generalized Markup Language (SGML) mais donne l'URL d'un document de suffixe le (.html.) Dans son livre Weaving the web3, Tim Berners-Lee explique sa décision de fonder le HTML sur le SGML trouvant ce dernier trop complexe. En effet, le compromis était d'attirer la communauté hypertexte qui considérait ce langage comme étant le plus prometteur pour standardiser le format des documents hypertexte, tout en y apportant la technicité du HTML.

Les éléments de base du langage HTML: Le titre du document; les hyperliens; la structuration du texte en titres, sous-titres, listes ou texte brut ainsi qu'un mécanisme rudimentaire de recherche par index. Le HyperText Markup Language ou dans sa forme abrégée le HTML est un language de balisage conçu pour représenter les pages web. Ce language permet d'écrire de l'HyperTexte et de structurer une page web en pouvant inclure liens, vidéos, images ou programmes informatiques. Le HTML est souvent combiné au CSS ainsi qu'aux language de programmation JavaScript pour animer et\ou donner du style au site.
