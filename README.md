# 💻 Les langages du web

Site éducatif qui présente les principaux **langages du web** : leur histoire, leur rôle et des exemples.

## 📌 Pages

| Page | Sujet |
|---|---|
| `index.html` / `Acceuil.html` | Accueil |
| `HTML.html` | Le langage HTML |
| `CSS.html` | L'histoire du CSS |
| `JavaScript.html` | Le langage JavaScript |
| `PHP.html` | Le langage PHP |

Chaque page a sa propre feuille de style (`stylehtml.css`, `stylecss.css`, `stylejs.css`, `stylephp.css`).

## 🛠️ Technologies

HTML5 · CSS3

## 🚀 Lancer le projet

Ouvrir `index.html` dans un navigateur.
