L'histoire du CSS

Présentation du langage:
 Les feuilles de style en cascade, généralement communémment CSS de l'anglais Cascading Style Sheets Le concept de feuille de style est présent depuis l'origine du World Wide Web : le premier navigateur web WorldWideWeb permet de mettre en forme les documents à l'aide de ce qui serait aujourd'hui considéré comme une « feuille de style utilisateur » Il ne s'agit cependant pas de styles déterminés par l'auteur du document. HTML ne comportant pas non plus d'éléments de présentation dans ses premières années. Pour palier à ce problème en 1994-1995, les premières propositions de styles externe: le « stylesheet proposal » de Pei Wei (créateur de Viola); les « Stylesheets for HTML » de Robert Raisch ( O'Reilly); les « Cascading HTML Style Sheets » (CHSS) de Håkon Wium Lie Le css permet de proposer une alternative à la structuration du HTML pour le faire évoluer en language de présentation. Le CSS permet donc de décorer et styliser la mise en page et le contenu du texte. Et plusieurs autres chose pour plus de précision je vous invite à cliquer sur le lien qui mène à la page wikipedia du CSS. Pour utiliser le css on peut implémentet la balise style dans son code HTML ou directement créé un fichier et juste penser à mettre un lien sur le code HTML que vous souhaiter styliser.
