Le Language PHP

Présentation du langage:
 PHP: Hypertext Preprocessor, plus connu sous son sigle PHP est un language de programmation. Utilisé principalement pour produire des site Web dynamiques via un serveur web PHP est un langage impératif orienté objet. Et a permis de créer des sites célébres comme Facebook et wikipedia. PHP est un langage de script utilisé le plus souvent côté serveur : dans cette architecture, le serveur interprète le code PHP des pages web demandées et génère du code (HTML, XHTML, CSS par exemple) et des données (JPEG, GIF, PNG par exemple) pouvant être interprétés et rendus par un navigateur web.

Le langage PHP a été créé en 1994 par Rasmus Lerdorf pour son site web. C'était à l'origine une bibliothèque logicielle en C. PHP s'appelait alors PHP/FI (pour Personal Home Page Tools/Form Interpreter). Ce travail a abouti un an plus tard à la version 3 de PHP, devenu alors PHP: Hypertext Preprocessor. Par la suite il mirent au point un nouveu moteur et c'est celui ci qui est la base de la version 4 de PHP.
